UBERAIRBNB (Expo + AWS Serverless)

Mobile app built with Expo / React Native (Expo Router) and an AWS backend built on Serverless Framework (Python 3.11).

Frontend: Expo Router app (routes in /app)

Backend: AWS HTTP API + WebSocket API + Lambdas + DynamoDB + S3 + Aurora Postgres (SQLAlchemy/pg8000)

Environment Variables
Frontend (root .env)

Create a .env at repo root:

EXPO_PUBLIC_GEOAPIFY_KEY=
EXPO_PUBLIC_API_BASE_URL=
EXPO_PUBLIC_AWS_REGION=ap-south-1
EXPO_PUBLIC_COGNITO_APP_CLIENT_ID=
EXPO_PUBLIC_COGNITO_USER_POOL_ID=

Expo reads EXPO*PUBLIC*\* at build time.

Backend (backend/.env)

Create backend/.env:

COGNITO_REGION=ap-south-1
COGNITO_USER_POOL_ID=ap-south-1_XXXXXX
COGNITO_APP_CLIENT_ID=YOUR_APP_CLIENT_ID
COGNITO_JWKS_URL=https://cognito-idp.ap-south-1.amazonaws.com/ap-south-1_XXXXXX/.well-known/jwks.json
LOG_LEVEL=INFO
DATABASE_URL=postgresql+pg8000://USER:PASS@<aurora-endpoint>:5432/<db>?sslmode=require

Backend uses SQLAlchemy + pg8000 for Postgres connectivity.

Install (Frontend)

From the repo root:

npm install

Run Frontend (iOS)

From the repo root:

npx expo prebuild
npx expo run:ios

Notes:

prebuild generates ios/ and android/

run:ios builds and launches the iOS app

If you change native dependencies and things get weird:

npx expo prebuild --clean
npx expo run:ios

Deploy Backend (AWS)

From backend/:

npx serverless deploy --stage dev --region ap-south-1

After deploy, update your root .env:

EXPO_PUBLIC_API_BASE_URL = the deployed HTTP API base URL

(If used by app) WebSocket URL from stack outputs (your backend outputs WebSocketApiUrl)

Database Migrations (Aurora Postgres)

From backend/ (make sure DATABASE_URL is set in backend/.env):

alembic revision -m "your message"
alembic upgrade head

Quick Health Checks

After deploy, verify:

GET /v1/health

GET /v1/health/db

Troubleshooting
401 Unauthorized on protected endpoints

Confirm frontend .env has correct:

EXPO_PUBLIC_COGNITO_USER_POOL_ID

EXPO_PUBLIC_COGNITO_APP_CLIENT_ID

Confirm backend backend/.env matches same pool/client

Confirm requests include:

Authorization: Bearer <idToken>

Serverless deploy VPC placeholders

Your backend config has placeholder IDs (vpc-xxxx, sg-xxxx, subnet-xxxx, rtb-xxxx). Replace with real values or remove VPC config for dev.
